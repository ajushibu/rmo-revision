The idea

The AV node is a slow, adjustable toll booth. It conducts slowly on purpose, and it tires: the sooner the next impulse arrives, the slower it conducts. So trouble builds up gradually (PR gets longer and longer) until one beat does not get through, the node rests, and it starts again. The vagus nerve also works the brake on it, so removing the vagal brake (atropine) helps.

The wire below it (His bundle and the two bundle branches) is a fast cable. It does not tire, so the PR stays the same, and when it is diseased a beat either gets through or does not. There is no build-up and no warning. It has no vagal brake, so atropine has nothing to remove.

Pick where the block is. Everything below the block has to find its own pacemaker.

Lower backup pacemakers are slower, wider and less dependable. That is the reason a block below the node is treated as an emergency even when the patient looks well.

Limits of this model. It is simplified teaching. Real blocks can sit at more than one level, Mobitz II can occasionally have a narrow QRS, and a Mobitz I with a wide QRS suggests disease below the node. The rule that atropine can worsen block below the node is standard teaching, which I did not find stated in ANZCOR 11.9; ANZCOR names atropine first-line for adverse signs, so in an unstable patient have pads on and be ready to pace. Numbers (PR, rates, thresholds) are illustrative, not measured.
